# xh Tool

xh Tool 是面向 PC 音游玩家的原生 Android 查分工具，作者为**鳕烩**。当前支持 **DJMAX RESPECT V 查分**、**osu!四模式查分 / 谱面搜索**与 **osu!mania 谱面分析**，需要 Android 8.0 及以上系统。

## 下载

- [CNB 下载](https://cnb.cool/linglin520/xh-tool/-/releases)
- [GitHub 下载](https://github.com/linglin520/xh-tool/releases/latest)

选择附件 `xh-Tool-0.2.1.apk` 安装。两站提供相同安装包；`SHA256SUMS.txt` 可用于核对文件摘要。此仓库用于发行 APK、更新资料和用户说明。

## 功能

- 使用 V-ARCHIVE 昵称或查询 Token 查看 4B / 5B / 6B / 8B 成绩、B70 / B30 / S10、DJ CLASS、Tier、统计、成长记录与吃分推荐。
- 浏览曲库、曲包和等级，搜索、筛选、收藏，查看谱面详情与雷达。
- 查看 Steam DLC 优惠、各区原币价格、价格历史、CLEAR PASS 档案和本地到期提醒。
- 支持演示模式、深浅主题、银白 / 金色 / 樱花粉外观和可调动效。

osu! 工具箱支持 bid / 谱面链接与 .osu / .osz 导入、HT / DT 快捷倍速和最近100条本地分析记录，可在右上角切换游戏进入；四模式玩家资料 / 最佳 / 最近成绩及谱面搜索需在“我的 → osu! API配置”填写自己的Client ID / Secret，仅在本机安全保存并直连官方；谱面预览暂未开放。不提供 PC 自动采集、OCR、云同步、多账号管理或旧应用数据导入。

## 开始使用

首次打开按“欢迎 → 绑定 V-ARCHIVE → 外观 → 完成”设置，已有昵称会预填，也可暂时先看看。之后可在“我的 → 查分玩家”修改配置；“我的 → 帮助”提供注册与使用说明。未绑定也可浏览曲库，历史从首次成功查询开始积累。

吃分推荐可设置当前键数的总 DJ POWER 目标；详情曲包跳转会临时显示完整曲库，离开后恢复原搜索和筛选。个人资料填写 QQ 号可获取公开头像，无需 QQ 登录；头像优先使用缓存，打开相关页面时按24小时规则检查更新，失败保留旧图。完成欢迎引导后普通升级不会再次自动显示，可在关于页主动重看。

xh Tool 与原 DJMAX Tool 独立安装，不覆盖旧应用。若曾安装使用调试签名的 xh Tool 内部测试包，首次正式版可能需要卸载该测试包再安装，卸载会删除其本地数据；请先确认需要保留的资料。之后请使用本仓库的正式包升级。

## B100成绩图与重新启动

在DJMAX成绩页点“B100成绩图”，可生成五列黑白海报，包含绑定QQ头像、完整DJ POWER和段位配色；Lord段位使用静态彩虹高光。支持放大、保存与分享，“重新绘制”先查新成绩再生成，失败保留旧图。重新启动从上次游戏模块首页进入；普通后台 / 外部应用返回保留当前页面。

## 更新与数据

在应用内检查更新，默认 CNB，也可选择 GitHub。发现更新后由你主动下载，校验完成后交给系统确认安装。不会下载旧 DJMAX Tool 的安装包。

数据与网络服务来自 V-ARCHIVE、EZ2PATTERN、Hangibot、Steam、小黑盒等，网络区域、账号权限和来源可用性会影响结果。应用内“关于”保留资料来源及许可说明。查询 Token 使用 Android Keystore 加密存储。作者头像只在打开关于页时检查缓存，不需要 QQ 登录。
